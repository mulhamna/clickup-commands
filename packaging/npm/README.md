# @mulham28/clickupc

**Unofficial** ClickUp CLI and MCP server in one binary. Not affiliated with ClickUp.

```bash
npm i -g @mulham28/clickupc
clickupc auth login
clickupc task list --mine
clickupc mcp install --client claude-code
```

The package downloads the `clickupc` binary for your platform from the matching
[GitHub Release](https://github.com/mulhamna/clickup-commands/releases) and
verifies it against the release's `checksums.txt`.

Docs: https://github.com/mulhamna/clickup-commands
